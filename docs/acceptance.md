### 算法与节点验证

59 个独立测试全部通过：传统检测 20、PnP 30、姿态历史 9。测试覆盖四点、相机模型、尺寸模式、深度、重投影、轴投影、候选选择、唯一匹配、丢失及时间异常。catkin 的嵌套汇总可能显示 118，独立数量以原始 XML 的 testcase 为准。

### 末尾片段连续性（2026-11-02 素材版本）

保持小板 135×56 mm、大板 230×56 mm，逐帧调用生产库对照。以下均读取对应原始 bag 的最后 3 秒；统计相邻两帧均为有效单目标、大小分类相同、中心偏移小于 20 px 的帧对。

| 数据集 | 输入帧 / 统计帧对 | 单帧选解：>30° 次数 / 最大变化 | 跨帧选解：>30° 次数 / 最大变化 |
|---|---|---|---|
| red_4 | 318 / 317 | 89 / 51.54° | 0 / 6.99° |
| red_1_3 | 249 / 117 | 16 / 68.18° | 0 / 11.74° |

通过公开入口回放 red_4 从 21.071 秒起的最后 3 秒、速度 0.2，实际接收 318 帧输入、315 帧 TF。314 组相邻 TF 无 >0.1 s 的间隔，>30° 变化为 0 次，最大变化 6.99°、P95 4.14°。四份 bag 的接口回归检查了时间戳、frame、TF 有限性及归一化、颜色 mask 与独立 HSV 逐像素一致性；小队列允许丢弃积压帧，以上数量不作为实时性能结论。

上述结果表明这些片段的大幅分支翻转减少，仍有抖动，不能证明首次分支、交叉换板或快速运动时的姿态正确。修改后的桌面效果及新增选解理解仍待本人明确反馈，不据自动结果代填全部掌握。

### 自动固定帧与进程行为

在隔离 ROS master 和 Xvfb 中实际运行安装后的启动器及 RViz，以下 8 项通过：无 CameraInfo 时等待；空 frame_id 不启动；自动选择常规相机坐标系；相同帧名不重启；自动读取新版 red_4 的实际帧名；任意新帧名触发切换；关闭 RViz 后启动器退出；有效但暂停的 ROS 模拟时间下关闭 launch 能清理查看器子进程。固定帧通过真实 RViz 进程参数核对，不依据数据集名称推断。
